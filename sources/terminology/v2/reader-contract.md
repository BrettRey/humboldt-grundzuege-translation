# Terminology record contract

Write one JSON object with `terms`, `candidate_reviews`, `page_reviews`, `limits` and `images_checked` to your own `sources/terminology/v2/readers/{range}-terms.json`. This is a source-grounded candidate return, not final authority. Do not edit another reader's files, the old register, sources or translations.

Each term has `headword`, `kind` (term/compound/phrase/grammatical_label), `forms` (observed inflections/spellings, not invented variants), `domain`, `senses`, and `relations` (objects with `type`, `target`, `reason`). Separate lexemes: do not put Geist/Verstand/Vernunft together. Inflections and spelling variants are not separate lexemes. A grammatical relation, its realization and the analyst's label need distinct definitions where the source distinguishes them.

Each sense has `label`, `definition`, `renderings` (array), `rule`, `caution`, `evidence` (array). Use source-specific senses, not a dictionary dump. Avoid splitting a lexical sense merely because its bearer changes unless its contribution or contrast changes. An ordinary expression can be included when its translation materially affects the argument.

Each evidence object has `printed_page`, `pdf_page`, `section` (nullable), `ocr_quote` (one exact contiguous excerpt from the normalized search page, max70words), `checked_quote` (image-confirmed wording, or null), `term_form` (the exact observed expression in the quote), `text_layer` (main_text/heading/editorial_apparatus/cited_example), `verification`, and `issue`. Image-check the short quotation supporting each operational sense; batch by page. Do not label an OCR quotation checked merely because the page was once sampled elsewhere. If an image correction differs, preserve both readings; do not force a false anchor. Use no modern linguistic example or definition from memory.

`candidate_reviews` is an array of groups: `{ids:[candidate IDs], disposition:included|ordinary|cited_example|proper_name|apparatus_only|ocr_noise|needs_review, target:headword or null, reason:short explanation}`. Each candidate ID appears exactly once. Included inflections can be grouped under their target. You must actually inspect exclusions; do not assign the entire unmatched remainder an automatic ordinary status. A rare consequential term is still eligible. Mechanical matches do not certify authorial occurrence.

`page_reviews` has one object per assigned printed page: page, included_headwords, omission_check (brief statement of the technical contrasts checked), unresolved_readings. `images_checked` lists actually inspected PDF pages and which evidence was checked. State any unsuccessful check and its consequence rather than inventing certainty. One evidenced local sense may suffice for a rare term; polysemous terms need the distinct contexts. No numeric headword target.

Selection covers the work's explanatory concepts, faculty vocabulary, classifications, linguistic operations, grammatical categories, sound/prosodic terms, technical method distinctions, and consequential metaphors. Language names and isolated foreign example tokens are normally scope exclusions, not missing glossary entries. All main-text pages are reviewed even if a page adds no headword. The dictionary/secondary comparison will be attached centrally; do not copy old group evidence indiscriminately into these records.
